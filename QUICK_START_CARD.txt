WHAT IS THIS?
─────────────────────────────────────────────────────────────────────────────────
One-way sync system that pulls recipes from production (DreamHost) to your local
server daily at 3 AM UTC. Production is the master, local is the replica.

DEPLOY IN 5 MINUTES
─────────────────────────────────────────────────────────────────────────────────

1. Copy script to local server:
   scp C:\Users\miket\Recipes_remote\sync_production_to_local.sh ethel@192.168.2.10:~/recipes_remote/

2. Make executable:
   ssh ethel@192.168.2.10 "chmod +x ~/recipes_remote/sync_production_to_local.sh"

3. Test manually:
   ssh ethel@192.168.2.10 "/home/ethel/recipes_remote/sync_production_to_local.sh"

4. Verify success (check log):
   ssh ethel@192.168.2.10 "tail -20 ~/recipes_remote/sync.log"

5. Schedule daily at 3 AM UTC:
   ssh ethel@192.168.2.10 "echo '0 3 * * * /home/ethel/recipes_remote/sync_production_to_local.sh' | crontab -"

WHAT HAPPENS WHEN IT RUNS
─────────────────────────────────────────────────────────────────────────────────
✓ Checks connectivity to both servers
✓ Backs up current local recipes.db (timestamped)
✓ Downloads new recipes.db from production
✓ Downloads saved_recipes_json/ directory
✓ Restarts Flask on local server
✓ Logs everything to sync.log
✓ Done! Local server now has production data

HOW TO CHECK IF IT WORKED
─────────────────────────────────────────────────────────────────────────────────
Check the log:
  ssh ethel@192.168.2.10 "tail -20 ~/recipes_remote/sync.log"

Count recipes (should match production):
  ssh ethel@192.168.2.10 "sqlite3 ~/recipes_remote/recipes.db 'SELECT COUNT(*) FROM recipes;'"

List backups created:
  ssh ethel@192.168.2.10 "ls -lh ~/recipes_remote/sync_backups/ | head -5"

Verify Flask is running:
  curl http://192.168.2.10:5000/ | grep -i "recipe" | wc -l

COMMON COMMANDS
─────────────────────────────────────────────────────────────────────────────────
Run sync manually anytime:
  ssh ethel@192.168.2.10 "/home/ethel/recipes_remote/sync_production_to_local.sh"

Check last 30 lines of log:
  ssh ethel@192.168.2.10 "tail -30 ~/recipes_remote/sync.log"

List all backups:
  ssh ethel@192.168.2.10 "ls -1 ~/recipes_remote/sync_backups/"

Restore from specific backup:
  ssh ethel@192.168.2.10 "cp ~/recipes_remote/sync_backups/recipes.db.backup_YYYYMMDD_HHMMSS ~/recipes_remote/recipes.db"
